# 🐍 100 Days of Code — Python

Este repositório reúne os projetos que desenvolvi durante o curso **[100 Days of Code: The Complete Python Pro Bootcamp](https://www.udemy.com/course/100-days-of-code/)**, da Dra. Angela Yu.

A proposta do curso é programar todos os dias durante 100 dias, construindo **um projeto por dia**. Começa com scripts simples de terminal e evolui para jogos com interface gráfica, automação com APIs e bots, aplicações web completas com Flask e banco de dados, e análise de dados com Pandas e Jupyter.

Cada pasta `DayXX...` é um projeto independente.

## 🧠 O que pratiquei

- **Fundamentos de Python:** variáveis, condicionais, loops, funções, listas e dicionários, escopo, depuração
- **Programação orientada a objetos:** classes, herança, organização de código em módulos
- **Interfaces gráficas:** `turtle` e `tkinter` (jogos e apps de desktop)
- **Arquivos e dados:** leitura e escrita de arquivos, CSV, JSON, tratamento de exceções, Pandas
- **APIs:** consumo de APIs REST com `requests`, autenticação, variáveis de ambiente, envio de e-mail com `smtplib`
- **Web scraping e automação:** BeautifulSoup, Selenium
- **Desenvolvimento web:** HTML, CSS, Bootstrap, Flask, Jinja, WTForms, SQLAlchemy, autenticação de usuários, criação de APIs REST, deploy
- **Ciência de dados:** Pandas, NumPy, Matplotlib, Seaborn, Plotly, regressão linear, testes estatísticos

## ▶️ Como rodar um projeto

```bash
cd Day64TopMovies
python -m venv venv
venv\Scripts\activate             # Windows
# source venv/bin/activate        # Linux / macOS
pip install -r requirements.txt   # quando o projeto tiver um
python main.py
```

Os notebooks de ciência de dados (dias 72–81, 99 e 100) podem ser abertos no Jupyter ou no Google Colab.

### 🔑 Chaves de API e senhas

Nenhuma credencial está no repositório. Os projetos que precisam de uma trazem um arquivo `.env.example`. Copie para `.env` e preencha com os seus valores:

```bash
copy .env.example .env    # Windows  (cp no Linux/macOS)
```
